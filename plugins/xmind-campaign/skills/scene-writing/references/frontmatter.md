# YAML Frontmatter Specification & Tag Taxonomy

## Required Frontmatter Fields

Every generated file must have:
```yaml
---
tags: [...]
aliases: []
---
```

Both fields are always present. `aliases` may be an empty list.

## Tag Taxonomy

### Content type tags (pick exactly one)
| Tag | Used for |
|-----|----------|
| `scene` | Scene, encounter, puzzle files (all go in Scenes/) |
| `npc` | NPC character files |
| `location` | Location files |
| `item` | Item files |
| `concept` | Concept/mechanic/faction files |

### Subtype tags (add when applicable, alongside content type)
| Tag | Used for |
|-----|----------|
| `encounter` | Scenes that are primarily combat encounters |
| `combat` | Same as above — add both `scene` and `encounter` and `combat` |
| `puzzle` | Scenes that are primarily puzzles or skill challenges |
| `boss` | Boss-level encounters or boss NPCs |
| `named` | Named enemies (not generic, have specific lore) |

### Source tags (always add)
| Tag | Meaning |
|-----|---------|
| `imported` | Generated by xmind-campaign plugin from XMind export |

### Chapter tags (add to all chapter-scoped content)
Format: `chapter-XX` where XX is zero-padded chapter number.
Examples: `chapter-01`, `chapter-03`, `chapter-12`

Do NOT add chapter tags to location, item, or concept files that span multiple chapters.

### Status tags (add when needed)
| Tag | Meaning |
|-----|---------|
| `has-image` | File has an embedded image |
| `needs-content` | Generated from image-only node — body is empty |
| `needs-review` | Generated with LOW classification confidence |
| `stub` | Generated from minimal notes — expand later |

## Full Examples

### Scene file
```yaml
---
tags: [scene, chapter-03, imported]
aliases: []
---
```

### Encounter file
```yaml
---
tags: [scene, encounter, combat, chapter-03, imported]
aliases: []
---
```

### Boss encounter
```yaml
---
tags: [scene, encounter, combat, boss, chapter-03, imported]
aliases: [The Lich King, Myrkul's Champion]
---
```

### NPC file
```yaml
---
tags: [npc, chapter-01, imported, has-image]
aliases: [Aldric the Smith, The Blacksmith]
---
```

### Location (multi-chapter)
```yaml
---
tags: [location, imported, has-image]
aliases: [The Mill, Old Mill]
---
```

### Item
```yaml
---
tags: [item, imported]
aliases: [Ring of Shadows]
---
```

### Needs review
```yaml
---
tags: [scene, chapter-02, imported, needs-review]
aliases: []
---
```

## Aliases

Populate `aliases` with:
- Common shortened names the DM might use when linking (`[[Aldric]]` vs `[[Aldric, the Blacksmith]]`)
- Danish name variants if the English title differs
- Alternative spellings from the XMind notes

If no aliases are relevant, leave as `[]`.

## Frontmatter Validation

Before writing any file, confirm:
- `tags` list is present and non-empty
- Exactly one content type tag is present
- `chapter-XX` tag is present for Scenes/ content, absent for vault-wide content
- `imported` tag is always present
- `aliases` field exists (even if empty list)

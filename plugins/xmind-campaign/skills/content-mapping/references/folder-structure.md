# Vault Folder Structure & Path Construction

## Expected Vault Root

The vault root is the campaign folder, e.g.:
```
/Users/priv/Documents/private-obsidian/DnD/The Plague of Myrkul/
```

The plugin asks for this path at the start of each run. It is stored in settings for the campaign.

## Full Folder Tree

```
[Campaign Name]/
├── CLAUDE.md                        # Campaign context for Claude
├── _Campaign Overview.md            # Quick reference
├── _import-log.md                   # Generated by plugin — cumulative import log
├── Chapters/
│   └── XX - Chapter Name - Canvas/
│       ├── Chapter Name.canvas      # Obsidian Canvas JSON
│       └── Scenes/                  # Atomic scene/encounter/puzzle files
│           ├── 01 - Scene Name.md
│           ├── 01a - Sub Scene.md
│           └── 02 - Next Scene.md
├── Characters/                      # NPC files + NPC images
│   ├── NPC Name.md
│   └── NPC Name.png
├── Locations/                       # Location files + location images
│   ├── Location Name.md
│   └── Location Name.jpg
├── Items/                           # Item files + item images
│   ├── Item Name.md
│   └── Item Name.png
├── Concepts/                        # Mechanics, factions, lore
│   └── Concept Name.md
├── Ideas/                           # Unrefined brainstorming (do not write here)
└── Outdated/                        # Superseded documents (do not write here)
```

## Path Construction Rules

### Chapter folder naming
Format: `XX - Chapter Name - Canvas`
- `XX` = zero-padded chapter number (e.g. `01`, `03`, `12`)
- Derive chapter number from the XMind branch order or ask user
- "Canvas" suffix is required by Obsidian Canvas convention

### Scene file naming
Format: `NN - Scene Name.md`
- `NN` = zero-padded scene number within the chapter
- Sub-scenes: `NNa`, `NNb`, etc. (e.g. `03a - Guard Tower Entry.md`)
- Derive order from XMind node order within the branch

### NPC, Location, Item, Concept naming
Format: `[Proper Name].md`
- Use the node title as-is (title case preserved)
- Strip leading/trailing whitespace
- Replace `/` or `:` in titles with `-`

### Canvas file path (vault-relative for Canvas JSON)
```
Chapters/XX - Chapter Name - Canvas/Scenes/01 - Scene Name.md
```
Always vault-relative, never absolute. This is what goes into the Canvas JSON `file` field.

## Image File Handling

Images in XMind are stored inside the ZIP under `resources/`. The `image.src` field looks like:
```
xap:resources/img-4a2f3b.png
```

Extraction steps:
1. Strip `xap:` prefix → `resources/img-4a2f3b.png`
2. The file is already extracted to `_extracted/resources/` by `extract_xmind.py`
3. Determine destination folder based on node type (see content-mapping SKILL.md)
4. Copy to vault: `[Campaign Root]/Characters/NPC Name.png`
5. Embed in Markdown: `![[Characters/NPC Name.png]]`

Use the original image extension. Do not convert formats.

## Settings File

The plugin stores the last-used vault path in:
```
~/.claude/xmind-campaign.local.md
```

Format:
```markdown
---
last_vault: /Users/priv/Documents/private-obsidian/DnD/The Plague of Myrkul
campaigns:
  - name: The Plague of Myrkul
    vault: /Users/priv/Documents/private-obsidian/DnD/The Plague of Myrkul
  - name: Curse of Strahd
    vault: /Users/priv/Documents/private-obsidian/DnD/Curse of Strahd
---

# XMind Campaign Plugin Settings

Edit the YAML frontmatter above to add campaigns or update vault paths.
```

At the start of each run, read this file. If a matching campaign name is found, offer it as the default path. Otherwise ask for the path and write it to the file.
